# InfoSecKe

Cybersecurity, Ethical Hacking, Linux, DevOps & Trading Technology Platform

## Features
- Cybersecurity tutorials and guides
- Ethical hacking labs and walkthroughs
- Linux administration and security
- DevOps and container security
- Trading technology and automation
- Tools and scripts for security professionals

## Tech Stack
- HTML5, CSS3, JavaScript
- Static site architecture
- Responsive design
- Dark/Light theme support

## Quick Start
1. Clone the repository: `git clone https://github.com/kitoi1/infosecke.git`
2. Open `index.html` in your browser
3. Start exploring the content!
