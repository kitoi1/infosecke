# Getting Started with InfoSecKe

Welcome to InfoSecKe! This guide will walk you through your first experience with the platform, from navigating the site to completing your first lab.

## Prerequisites

Before you begin, make sure you have:

- Completed the [installation](/docs/installation) of the platform locally (or you’re using the hosted version).
- Basic familiarity with a terminal and a web browser.
- A desire to learn cybersecurity – no prior experience required.

<Callout type="info" title="New to cybersecurity?">
  Start with the <a href="/learn/getting-started">Cybersecurity Roadmap</a> for a structured learning path.
</Callout>

<Callout type="warning" title="Heads up">
  Always back up your data first.
</Callout>

## Exploring the Platform

The main sections you’ll interact with are:

1. **Learn** – Structured courses covering fundamentals, Linux, networking, and security.
2. **Labs** – Hands-on, practical exercises where you apply what you’ve learned.
3. **Tools** – Guides and references for essential security tools (Nmap, Burp Suite, Wireshark, etc.).
4. **Blog & Research** – Community articles, case studies, and write‑ups.
5. **Docs** – You are here! Documentation and platform guides.

Use the top navigation bar or the search feature to jump directly to any topic.

## Your First Learning Path

We recommend every beginner follows this sequence to build a solid foundation:

<Steps>
  <Step title="Understand the basics">
    Start with <a href="/learn/internet-and-networking">Internet & Networking</a> and <a href="/learn/basics-of-computers">Basics of Computers</a>.  
    These modules explain how data moves, what IP addresses are, and how operating systems work.
  </Step>

  <Step title="Learn Linux essentials">
    Move to <a href="/linux/linux-introduction">Linux Introduction</a> and <a href="/linux/bash-basics">Bash Basics</a>.  
    Most security tools run on Linux – comfort with the command line is crucial.
  </Step>

  <Step title="Get security‑aware">
    Read <a href="/cybersecurity/what-is-cybersecurity">What is Cybersecurity</a> and <a href="/learn/security-basics">Security Basics</a>.  
    You’ll learn about threats, vulnerabilities, and the CIA triad.
  </Step>

  <Step title="Try your first lab">
    Head to <a href="/labs/linux-practice-lab">Linux Practice Lab</a> or <a href="/labs/ctf-introduction">CTF Introduction</a>.  
    Apply your new knowledge in a safe, sandboxed environment.
  </Step>
</Steps>

## Using the Labs

Labs are the heart of InfoSecKe. They are interactive, browser‑based exercises that teach real‑world skills.

- **No setup required** – Labs run directly in your browser using isolated containers.
- **Step‑by‑step instructions** – Each lab includes a clear objective and guided tasks.
- **Instant feedback** – You’ll know immediately if you completed a task correctly.

To access a lab, simply navigate to the **Labs** section, choose a topic, and click **Start Lab**.

<Callout type="success" title="Pro Tip">
  Read the lab instructions completely before clicking around. It saves time and helps you understand the goal.
</Callout>

## Tracking Your Progress

While InfoSecKe is open‑source and doesn’t require an account to use, you can still:

- Bookmark pages to keep track of where you left off.
- Star or “complete” labs mentally – we’re working on a local progress tracker.
- Join our <a href="https://discord.gg/infosecke">Discord community</a> to share your milestones and get help.

## Next Steps

Once you’re comfortable with the basics:

- Explore the **Ethical Hacking** path to learn offensive techniques safely.
- Read the **Tools** guides to master Nmap, Burp Suite, and more.
- Check out the **Research** section for real‑world case studies and write‑up templates.
- Start contributing to the platform – see our [Contributing Guide](/docs/contributing).

Happy learning, and welcome aboard!
