# Installation Guide

This guide shows you how to set up InfoSecKe locally so you can explore the documentation platform, contribute content, and test new features in your own environment.

<Callout type="info" title="Before You Start">
  Make sure you have [Node.js](https://nodejs.org/) installed before continuing.
</Callout>

## Prerequisites

Before installing InfoSecKe, ensure you have:

- Node.js 18 or later.
- npm, pnpm, or yarn installed.
- Git installed on your machine.

## Clone the repository

```bash
git clone https://github.com/kitoi1/infosecke.git
cd infosecke
```

## Install dependencies

Use your preferred package manager:

```bash
npm install
```

Or, if you use pnpm:

```bash
pnpm install
```

## Start the development server

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## Verify the setup

If everything is working correctly, you should see the InfoSecKe homepage running locally.

## Common issues

- If the app fails to start, confirm that Node.js is installed correctly.
- If dependencies fail to install, delete `node_modules` and reinstall.
- If the port is already in use, stop the other process or run the app on a different port.
