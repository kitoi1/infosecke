# Getting Started with InfoSecKe

Welcome! This guide will help you move from installation to your first hands‑on lab as quickly as possible.

## Prerequisites

- Completed the [installation](/docs/installation) (local or cloud).
- Basic comfort with a terminal and a web browser.
- No prior security knowledge required.

<Callout type="info" title="New to cybersecurity?">
  Start with the <a href="/learn/getting-started">Cybersecurity Roadmap</a> to see a structured learning path.
</Callout>

<Callout type="warning" title="Heads up">
  Always back up your data first.
</Callout>

## Navigating the Platform

| Section     | Purpose |
|-------------|---------|
| **Learn**   | Structured courses – Linux, networking, security fundamentals |
| **Labs**    | Browser‑based, hands‑on exercises with instant feedback |
| **Tools**   | Guides and reference for essential security tools |
| **Docs**    | You are here – platform documentation and guides |
| **Blog**    | Community articles, case studies, and release notes |

## Recommended Beginner Path

Follow this sequence to build a strong foundation:

<Steps>
  <Step title="Understand the basics">
    Complete <a href="/learn/internet-and-networking">Internet & Networking</a> and <a href="/learn/basics-of-computers">Basics of Computers</a>.  
    Learn how data moves, what IP addresses are, and how operating systems work.
  </Step>

  <Step title="Learn Linux essentials">
    Move to <a href="/linux/linux-introduction">Linux Introduction</a> and <a href="/linux/bash-basics">Bash Basics</a>.  
    Most security tools run on Linux – comfort with the command line is critical.
  </Step>

  <Step title="Get security‑aware">
    Read <a href="/cybersecurity/what-is-cybersecurity">What is Cybersecurity</a> and <a href="/learn/security-basics">Security Basics</a>.  
    Understand threats, vulnerabilities, and the CIA triad.
  </Step>

  <Step title="Try your first lab">
    Head to <a href="/labs/linux-practice-lab">Linux Practice Lab</a> or <a href="/labs/ctf-introduction">CTF Introduction</a>.  
    Apply what you’ve learned in a safe, sandboxed environment.
  </Step>
</Steps>

## Using the Labs

- **No setup** – everything runs in your browser using isolated containers.
- **Step‑by‑step instructions** – each lab has a clear objective and guided tasks.
- **Instant feedback** – you’ll know immediately if a step is correct.

<Callout type="success" title="Pro Tip">
  Read the entire lab instructions before interacting. It saves time and helps you understand the goal.
</Callout>

## Tracking Your Progress

While the platform doesn’t require an account, you can:

- Bookmark pages to keep your place.
- Join the <a href="https://discord.gg/infosecke">Discord community</a> to share milestones.
- Use the local search to revisit topics quickly.

## Next Steps

Once you’re comfortable with the basics, explore:

- **Ethical Hacking** path – learn offensive techniques safely.
- **Tools** guides – Nmap, Burp Suite, Wireshark, and more.
- **Research** section – real‑world case studies and write‑ups.
- **Contributing** – help improve the platform: see the [Contributing Guide](/docs/contributing).

Happy learning, and welcome to InfoSecKe!
