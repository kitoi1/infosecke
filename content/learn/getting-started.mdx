InfoSecKe is an open-source platform for cybersecurity education, documentation, and community learning. This guide explains how the content is organized and how to study effectively.

## How Content Is Organized

Articles are grouped by topic:

- **Learn** — onboarding and structured guides.
- **Cybersecurity** — defensive security concepts and practices.
- **Ethical Hacking** — authorized testing methodologies.
- **Linux** — command-line and system administration skills.
- **Research** — technical analysis and write-ups.

Each article includes metadata such as reading time, tags, and publication date to help you choose material at the right level.

## Recommended Learning Approach

A practical study workflow looks like this:

1. Read the concept article.
2. Reproduce examples in a safe lab environment.
3. Take notes on commands, tools, and failure modes.
4. Review related articles to deepen context.

Never test techniques against systems you do not own or lack explicit permission to assess.

## Using Code Examples

Code blocks support syntax highlighting for common languages and shells:

```bash
# Verify your environment before running security tools
uname -a
whoami
```

Copy examples into your own lab, then modify them to understand behavior rather than memorizing output.

## Contributing

InfoSecKe is open source. Contributions should be accurate, ethical, and accessible to learners. When adding content, create a new MDX file with frontmatter and write in clear, professional language.
